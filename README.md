# Виселица (Hangman) — консольная игра на C#

Классическая игра «Виселица» для терминала. Угадывайте буквы, пока не кончатся попытки.

## Возможности

- Случайное слово из встроенного словаря
- Ограниченное число попыток (по умолчанию — 6)
- Отображение текущего состояния слова и уже использованных букв
- Защита от повторного ввода одной и той же буквы
- Простой ASCII-интерфейс в консоли

## Требования

- [.NET SDK](https://dotnet.microsoft.com/download) 6.0 или выше
- Терминал с поддержкой Unicode (для корректного отображения символов)

## Установка

```bash
git clone https://github.com/username/Viselitsa.git
cd Viselitsa
```

## Запуск

```bash
dotnet run
```

Или соберите релизную версию:

```bash
dotnet build -c Release
dotnet run -c Release
```

## Как играть

1. Программа загадывает слово и показывает его в виде `_ _ _ _ _`.
2. Вводите по одной букве и нажимайте Enter.
3. За каждую неверную букву теряется одна попытка.
4. Победа — когда открыты все буквы. Поражение — когда попытки закончились.
